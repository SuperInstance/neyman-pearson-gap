# neyman-pearson-gap

A [SuperInstance](https://github.com/SuperInstance) crate.

## Ecosystem Integration

- Applies Neyman-Pearson hypothesis testing to spectral graph gaps for optimal decision boundaries
- Uses `spectral-graph-core` for spectral data extraction
- Complements `spectral-deadband` — deadband detects gaps, Neyman-Pearson validates them
- Part of the statistical spectral analysis pipeline
- Enables rigorous false-positive control in spectral change detection
